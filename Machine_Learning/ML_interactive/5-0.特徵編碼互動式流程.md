## 🚀 步驟 1：識別要編碼的特徵 (Identify Features to Encode)

首先，我們需要找出資料集中所有 `object` 型態（通常是文字）或其他需要編碼的類別型欄位。

**【CODE】執行程式碼**
> 這段程式碼會自動幫你篩選出所有非數值的欄位。

```python
# 創建一個副本以進行操作
df_encoded = df_featured.copy()

# 選出 object 型態的欄位，這些是我們需要編碼的主要對象
categorical_cols = df_encoded.select_dtypes(include=['object', 'category']).columns.tolist()

if categorical_cols:
    print("--- 需要進行編碼的類別型特徵 ---")
    print(categorical_cols)
    # 顯示每個類別特徵的唯一值數量
    for col in categorical_cols:
        print(f"  - '{col}': {df_encoded[col].nunique()} 個唯一值")
else:
    print("✅ 資料集中沒有找到需要編碼的類別型特徵。")

```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：列表中的就是我們要處理的目標。同時，我們也列出了每個特徵的「唯一值數量」(nunique)。這個數量對於我們選擇編碼策略至關重要。
> *   **Why (思考)**：如果一個類別特徵的唯一值非常多（例如，超過 50 個），我們稱之為「高基數」特徵。對其使用常規的獨熱編碼會產生大量新欄位，可能導致「維度災難」。

## 🚀 步驟 2：選擇編碼策略 (Choosing an Encoding Strategy)

**【THINK】領航員引導式提問**
> **這是最關鍵的一步！** 對於上面找出的類別特徵，你需要判斷它們是 **有序的 (Ordinal)** 還是 **無序的 (Nominal)**？
> *   **有序 (Ordinal)**：類別之間有明確的等級或順序關係。例如：`評價` (`差`, `中`, `好`)，`學歷` (`高中`, `大學`, `碩士`)。
> *   **無序 (Nominal)**：類別之間沒有內在的順序，是平等的。例如：`性別` (`男`, `女`)，`城市` (`台北`, `東京`, `紐約`)。

> *   **無序特徵列表**: `[請填寫]`

## 🚀 步驟 3：執行編碼 (Applying Encoders)

根據你的分類，我們將採用不同的策略。
*   對於**有序特徵**，我們使用 **標籤編碼 (Label Encoding)**，將 `(差, 中, 好)` 映射為 `(0, 1, 2)`，保留其順序性。
*   對於**無序特徵**，我們使用 **獨熱編碼 (One-Hot Encoding)**，為每個類別創建一個新的二元 (0/1) 欄位，避免引入不存在的順序關係。

**【CODE】執行程式碼**
> `pandas` 的 `map` 和 `get_dummies` 函數可以讓我們輕鬆完成這兩項任務。

```python
# --- 使用者需修改的區域 ---

# 1. 處理有序特徵 (Label Encoding)
# 範例：為 'cut' (鑽石切工) 特徵手動定義順序
cut_mapping = {'Fair': 0, 'Good': 1, 'Very Good': 2, 'Premium': 3, 'Ideal': 4}
if 'cut' in df_encoded.columns:
    df_encoded['cut_encoded'] = df_encoded['cut'].map(cut_mapping)
    print("✅ 已對 'cut' 欄位進行標籤編碼。")

# 2. 處理無序特徵 (One-Hot Encoding)
# 範例：對 'color' 和 'clarity' 進行獨熱編碼
nominal_cols_to_encode = ['sex', 'embarked'] # <-- 請填入你的無序特徵列表

# -------------------------

# 篩選出實際存在的欄位
nominal_cols_to_encode = [col for col in nominal_cols_to_encode if col in df_encoded.columns]

if nominal_cols_to_encode:
    # 使用 get_dummies 進行獨熱編碼
    # drop_first=True 是為了避免「虛擬變數陷阱」，可以減少一個維度，對於線性模型很重要
    df_one_hot = pd.get_dummies(df_encoded[nominal_cols_to_encode], drop_first=True, dtype=int)
    
    # 將編碼後的新欄位合併回主 DataFrame
    df_encoded = pd.concat([df_encoded, df_one_hot], axis=1)
    
    # 刪除原始的類別欄位
    df_encoded.drop(columns=nominal_cols_to_encode, inplace=True)
    
    print(f"\n✅ 已對 {nominal_cols_to_encode} 欄位進行獨熱編碼。")
    print("--- 新增的獨熱編碼特徵預覽 ---")
    display(df_one_hot.head())
else:
    print("\n沒有需要進行獨熱編碼的欄位。")

# 刪除其他未處理的 object 欄位（如果有的話）
final_categorical_cols = df_encoded.select_dtypes(include=['object', 'category']).columns.tolist()
if final_categorical_cols:
    df_encoded.drop(columns=final_categorical_cols, inplace=True)
    print(f"\n已移除剩餘的原始類別欄位: {final_categorical_cols}")

print("\n--- 編碼後的資料集預覽 ---")
display(df_encoded.head())
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：`sex` 欄位消失了，取而代之的是一個新的 `sex_male` 欄位，用 `1` 代表男性，`0` 代表女性。這就是獨熱編碼。
> *   **Why (思考)**：為什麼要 `drop_first=True`？以 `sex` 為例，我們只需要 `sex_male` 一個欄位就夠了。如果 `sex_male` 是 `1`，那他就是男性；如果是 `0`，那他必然是女性。`sex_female` 欄位的資訊是多餘的，保留它會導致**多重共線性**，影響某些模型的穩定性。
> *   **How (行動)**：將你在步驟2中分類的「無序特徵」填入 `nominal_cols_to_encode` 列表，並執行程式碼，即可完成對它們的翻譯工作。
