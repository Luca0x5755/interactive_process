## 🚀 A 部分：分類模型評估 (Classification Evaluation)

如果你的任務是分類，那麼準確率 (Accuracy) 絕不是唯一的指標。我們需要更精細的工具。

### **A1. 混淆矩陣 (Confusion Matrix)**

混淆矩陣是所有分類評估指標的基礎，它詳細地展示了「模型預測」與「真實標籤」之間的對應關係。

**【CODE】執行程式碼**

```python
from sklearn.metrics import confusion_matrix, classification_report, roc_curve, auc
import seaborn as sns

# 假設 model, X_test, y_test 已準備好
if 'model' in locals() and 'y_test' in locals() and model.predict(X_test).dtype == y_test.dtype:
    y_pred = model.predict(X_test)
    cm = confusion_matrix(y_test, y_pred)

    plt.figure(figsize=(8, 6))
    sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', 
                xticklabels=model.classes_, yticklabels=model.classes_)
    plt.title('Confusion Matrix')
    plt.ylabel('Actual')
    plt.xlabel('Predicted')
    plt.show()
```

**【ANALYSIS】領航員深度解析**
> *   **TP (True Positive)**: 右下角。真實為正，預測也為正。（預測正確）
> *   **TN (True Negative)**: 左上角。真實為負，預測也為負。（預測正確）
> *   **FP (False Positive)**: 右上角。真實為負，預測為正。（**Type I Error**，誤報）
> *   **FN (False Negative)**: 左下角。真實為正，預測為負。（**Type II Error**，漏報）

### **A2. 精確率(Precision), 召回率(Recall) & F1-Score**

- **精確率 (Precision)** = `TP / (TP + FP)`
  - **問**: 在所有被模型預測為「正」的樣本中，有多少是真正的「正」？
  - **意義**: 衡量模型的「查準率」，高精確率代表模型的預測可信度高。
- **召回率 (Recall)** = `TP / (TP + FN)`
  - **問**: 在所有真正的「正」樣本中，有多少被模型成功地「找回來」了？
  - **意義**: 衡量模型的「查全率」，高召回率代表模型能盡可能地找出所有正例。
- **F1-Score**: 精確率和召回率的調和平均數，是一個綜合性指標。

**【CODE】執行程式碼**

```python
if 'y_pred' in locals():
    print(classification_report(y_test, y_pred))
```

### **A3. ROC 曲線 與 AUC 值**

**ROC 曲線** 描繪了在所有可能的分類閾值下，**真正率 (TPR, 即Recall)** vs. **假正率 (FPR)** 的關係。曲線越靠近左上角，模型性能越好。
**AUC (Area Under Curve)** 是 ROC 曲線下的面積，值在 0.5 到 1 之間。AUC 越接近 1，模型的區分能力越強。

**【CODE】執行程式碼**

```python
if hasattr(model, 'predict_proba'):
    y_pred_proba = model.predict_proba(X_test)[:, 1]
    fpr, tpr, _ = roc_curve(y_test, y_pred_proba)
    roc_auc = auc(fpr, tpr)

    plt.figure(figsize=(8, 6))
    plt.plot(fpr, tpr, color='darkorange', lw=2, label=f'ROC curve (area = {roc_auc:.2f})')
    plt.plot([0, 1], [0, 1], color='navy', lw=2, linestyle='--')
    plt.xlabel('False Positive Rate')
    plt.ylabel('True Positive Rate')
    plt.title('Receiver Operating Characteristic (ROC) Curve')
    plt.legend(loc="lower right")
    plt.show()
```

## 🚀 B 部分：迴歸模型評估 (Regression Evaluation)

### **B1. 核心指標**

- **MAE (平均絕對誤差)**: 預測的平均誤差大小，單位與目標相同，易於理解。
- **RMSE (均方根誤差)**: 與 MAE 類似，但對大誤差的懲罰更重。
- **R² (決定係數)**: 衡量模型能解釋目標變異性的百分比，越接近1越好。

### **B2. 殘差圖 (Residuals Plot)**

殘差圖是診斷迴歸模型的利器。**殘差 = 真實值 - 預測值**。我們希望殘差是隨機分佈的。

**【CODE】執行程式碼**

```python
# 假設 model, X_test, y_test 已準備好
if 'model' in locals() and 'y_test' in locals() and not isinstance(y_test.iloc[0], (str, bool)):
    y_pred = model.predict(X_test)
    residuals = y_test - y_pred

    plt.figure(figsize=(8, 6))
    sns.scatterplot(x=y_pred, y=residuals)
    plt.axhline(y=0, color='r', linestyle='--')
    plt.title('Residuals vs. Predicted Values')
    plt.xlabel('Predicted Values')
    plt.ylabel('Residuals')
    plt.show()
```

**【ANALYSIS】領航員深度解析**
> *   **理想情況**: 點應該在 y=0 的水平線上下隨機、均勻地散佈，沒有任何明顯的模式。
> *   **問題信號**: 如果點呈現出喇叭狀（異方差性）、曲線狀（非線性關係未被捕捉）或其他模式，都說明你的模型還有改進空間。

## 🚀 C 部分：模型改進技術

### **C1. 交叉驗證 (Cross-Validation)**

單次劃分訓練/測試集可能存在偶然性。**K-折交叉驗證**是一種更穩健的評估方法。它將訓練集分成 K 份，輪流用其中 1 份做驗證，其他 K-1 份做訓練，重複 K 次，最後取平均性能。

**【CODE】執行程式碼**

```python
from sklearn.model_selection import cross_val_score

if 'model' in locals() and 'X_train' in locals():
    # 使用5折交叉驗證
    scores = cross_val_score(model, X_train, y_train, cv=5, scoring='accuracy') # 分類任務
    # scores = cross_val_score(model, X_train, y_train, cv=5, scoring='r2') # 迴歸任務
    
    print(f"交叉驗證分數: {scores}")
    print(f"平均分數: {scores.mean():.4f} (+/- {scores.std() * 2:.4f})")
```

### **C2. 超參數調優 (Hyperparameter Tuning)**

模型的很多參數（如隨機森林的樹的數量）需要我們手動設定，這些稱為**超參數**。**網格搜索 (Grid Search)** 是一種自動尋找最佳超參數組合的方法。

**【CODE】執行程式碼**

```python
from sklearn.model_selection import GridSearchCV
from sklearn.ensemble import RandomForestClassifier

if 'X_train' in locals():
    # 定義要搜索的參數網格
    param_grid = {
        'n_estimators': [50, 100, 150],
        'max_depth': [None, 10, 20]
    }
    # 初始化網格搜索
    grid_search = GridSearchCV(estimator=RandomForestClassifier(random_state=42), 
                               param_grid=param_grid, cv=3, n_jobs=-1, verbose=1)
    
    print("--- 開始進行網格搜索... ---")
    grid_search.fit(X_train, y_train)
    print("網格搜索完成！")
    print(f"找到的最佳參數: {grid_search.best_params_}")
    
    # 使用最佳模型
    best_model = grid_search.best_estimator_
```
