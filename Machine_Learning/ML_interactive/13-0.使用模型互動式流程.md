## 🚀 步驟 1：建立完整的預測流程

**【THINK】領航員引導式提問**
> 一個常見的誤解是，使用模型就是簡單地 `model.predict(new_data)`。但這是不對的！
>
> **黃金準則**: 新的原始數據必須經過**與訓練數據完全相同**的預處理步驟，才能被模型正確地理解。這意味著我們的預測流程應該是：
> 1.  **接收原始新數據** (例如，一個包含用戶信息的字典)。
> 2.  **特徵工程**: 對新數據執行與 `4-0` 章節完全相同的特徵創造。
> 3.  **特徵編碼**: 對新數據執行與 `5-0` 章節完全相同的特徵編碼。
> 4.  **特徵縮放**: 使用在 `12-0` 中保存的、**已經被訓練集 `fit` 過的 `scaler`**，對新數據進行 `transform`。
> 5.  **模型預測**: 將處理好的數據送入模型，得到最終結果。

---

## 🚀 步驟 2：執行預測

**【CODE】執行程式碼**
> 下面的程式碼將上述完整流程封裝成一個函數。你可以修改 `new_data` 字典中的值，來測試不同的輸入會得到什麼樣的預測結果。

```python
import joblib
import pandas as pd
import numpy as np

def predict_new_data(raw_data):
    """
    一個完整的預測函數，接收原始字典數據，輸出預測結果。
    """
    try:
        # 1. 載入模型和 Scaler
        model = joblib.load('final_model.joblib')
        scaler = joblib.load('scaler.joblib')
        
        # 假設我們知道模型訓練時最終使用的欄位順序和需要縮放的欄位
        # 這通常會在專案中被記錄和保存下來
        FINAL_MODEL_COLUMNS = model.feature_names_in_ # scikit-learn 0.24+ 
        FEATURES_TO_SCALE = scaler.feature_names_in_ # scikit-learn 1.0+

    except FileNotFoundError:
        print("❌ 錯誤：找不到 'final_model.joblib' 或 'scaler.joblib'。")
        return None

    # 2. 將原始數據轉換為 DataFrame
    df = pd.DataFrame([raw_data])

    # 3. 複製特徵工程 (與訓練時保持一致)
    # 這裡以一個保險費用預測的例子來示範
    # --- 特徵創造 ---
    df['age^2'] = df['age'] ** 2
    df['is_obese'] = (df['bmi'] >= 30).astype(int)
    df['age_bmi'] = df['age'] * df['bmi']
    # --- 特徵編碼 ---
    df['sex_male'] = (df['sex'] == 'male').astype(int)
    df['smoker_yes'] = (df['smoker'] == 'yes').astype(int)
    # --- 獨熱編碼 ---
    for region in ['northwest', 'southeast', 'southwest']:
        df[f'region_{region}'] = (df['region'] == region).astype(int)

    # 4. 整理欄位，確保順序和數量與模型訓練時完全一致
    try:
        features_df = df[FINAL_MODEL_COLUMNS]
    except KeyError as e:
        print(f"❌ 錯誤：輸入數據缺少必要的欄位或特徵工程不一致。缺失: {e}")
        return None

    # 5. 特徵縮放 (使用已保存的 scaler)
    features_df[FEATURES_TO_SCALE] = scaler.transform(features_df[FEATURES_TO_SCALE])

    # 6. 執行預測
    prediction = model.predict(features_df)
    prediction_proba = model.predict_proba(features_df) if hasattr(model, 'predict_proba') else None

    return prediction[0], prediction_proba[0] if prediction_proba is not None else None

# --- 使用者需修改的區域 ---
# 提供一筆新的、從未見過的原始數據
new_data = {
    'age': 35,
    'sex': 'male',
    'bmi': 28.5,
    'children': 1,
    'smoker': 'no',
    'region': 'southwest'
}
# -------------------------

# 執行預測流程
final_prediction, final_proba = predict_new_data(new_data)

if final_prediction is not None:
    print("\n--- 預測流程執行成功 ---")
    print(f"輸入的原始數據: {new_data}")
    print(f"\n🎯 最終預測結果: {final_prediction}")
    if final_proba is not None:
        print(f"屬於各類別的機率: {final_proba}")

```

> *   **Why (思考)**：這個 `predict_new_data` 函數是整個專案的核心價值所在。它封裝了所有複雜的處理邏輯，提供了一個簡單的接口。在真實世界的應用中，這個函數可以被一個網站後端、一個數據分析腳本或一個定時任務所調用。
> *   **How (行動)**：嘗試修改 `new_data` 中的值，看看不同的輸入如何影響最終的預測結果。例如，將 `smoker` 從 `'no'` 改為 `'yes'`，預測的費用是否會大幅上升？這有助於你理解模型的行為。
