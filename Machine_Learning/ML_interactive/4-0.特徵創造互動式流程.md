## 🚀 步驟 1：交互特徵與多項式特徵 (Interaction & Polynomial Features)

有時，特徵之間的「化學反應」比特徵本身更重要。例如，`房間的長度`和`寬度`本身對房價有影響，但它們的乘積——`面積`——顯然是個更強大的預測特徵。

**【THINK】領航員引導式提問**
> 思考一下，你的數值型特徵之間，是否存在有意義的比例或乘積關係？（例如：`總收入` / `家庭成員數` = `人均收入`）

**【CODE】執行程式碼**
> 我們可以手動創建這些交互特徵，也可以使用 `scikit-learn` 的 `PolynomialFeatures` 自動生成。後者不僅能生成 `a*b` 這樣的交互項，還能生成 `a^2`, `b^2` 這樣的多項式項，幫助線性模型捕捉非線性關係。

```python
from sklearn.preprocessing import PolynomialFeatures

# 創建一個副本以進行操作
df_featured = df_processed.copy()

# --- 使用者需修改的區域 ---

# 1. 手動創建交互特徵 (基於業務理解)
# 範例：計算 '人均收入'
if 'total_income' in df_featured.columns and 'family_members' in df_featured.columns:
    epsilon = 1e-6 # 避免除以零
    df_featured['income_per_person'] = df_featured['total_income'] / (df_featured['family_members'] + epsilon)
    print("✅ 已手動創造新特徵 'income_per_person'。")

# 2. 自動生成多項式與交互特徵
# 注意：選擇過多特徵會導致維度爆炸，建議選擇你認為最重要的 2-3 個數值特徵
poly_features_to_use = ['age', 'fare'] # <-- 請替換成你認為重要的數值特徵
degree = 2 # 2次多項式

# -------------------------

# 確保選擇的欄位存在
poly_features_to_use = [f for f in poly_features_to_use if f in df_featured.columns]

if len(poly_features_to_use) > 1:
    poly = PolynomialFeatures(degree=degree, include_bias=False)
    poly_features = poly.fit_transform(df_featured[poly_features_to_use])
    poly_feature_names = poly.get_feature_names_out(poly_features_to_use)
    df_poly = pd.DataFrame(poly_features, columns=poly_feature_names, index=df_featured.index)

    # 為了避免重複，我們刪除原始欄位，只保留擴展後的新特徵
    df_featured = pd.concat([df_featured.drop(columns=poly_features_to_use), df_poly], axis=1)

    print(f"\n✅ 已為 {poly_features_to_use} 成功生成 {degree} 次多項式特徵。")
    print("--- 新增的特徵預覽 ---")
    display(df_poly.head())
else:
    print("\n⚠️ 未選擇足夠的特徵來進行多項式擴展，跳過此步驟。")
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：如果原始特徵是 `[a, b]`，二次多項式特徵會產生 `[a, b, a^2, a*b, b^2]`。這些新特徵讓線性模型有能力學習更複雜的模式。
> *   **Why (思考)**：手動創建依賴領域知識，能創造出解釋性強的特徵。自動生成則是一種探索性的方法，能發現我們未曾想到的關係。但它會顯著增加特徵數量（維度災難），可能會提高模型過擬合的風險，因此後續的**特徵選擇**將非常重要。

## 🚀 步驟 2：分組聚合特徵 (Group Aggregation Features)

這是一種極其強大的技術，它能從「個體」行為中，提煉出「群體」的洞察。例如，我們可以按 `Department`（部門）分組，然後計算該部門員工的平均薪水、最高年齡等，用這些「群體統計值」來豐富每個員工的特徵。

**【THINK】領航員引導式提問**
> 觀察你的類別型欄位（如 `部門`、`城市`、`性別`），你認為基於哪個欄位進行分組，能為資料帶來更有價值的上下文資訊？

**【CODE】執行程式碼**
> 我們將使用 `pandas` 的 `groupby()` 和 `agg()` 方法來實現。

```python
# --- 使用者需修改的區域 ---
# 選擇一個類別型特徵進行分組
group_by_col = 'pclass' # <-- 請替換成你想分組的類別欄位，例如 'department'

# 定義要對哪些數值特徵進行何種統計
agg_config = {
    'fare': ['mean', 'std'],  # <-- 計算 'fare' 的平均值和標準差
    'age': ['max', 'min']      # <-- 計算 'age' 的最大值和最小值
}
# -------------------------

if group_by_col in df_featured.columns:
    # 確保聚合的欄位存在
    valid_agg_config = {k: v for k, v in agg_config.items() if k in df_featured.columns}

    if valid_agg_config:
        print(f"--- 按 '{group_by_col}' 分組，對 {list(valid_agg_config.keys())} 進行聚合 ---")
        
        # 執行分組聚合
        group_agg = df_featured.groupby(group_by_col).agg(valid_agg_config)
        
        # 展平多級索引的列名，例如 (fare, mean) -> fare_mean
        group_agg.columns = ['_of_'.join(col).strip() for col in group_agg.columns.values]
        group_agg.reset_index(inplace=True)

        print("聚合出的新特徵：")
        display(group_agg)

        # 將聚合特徵合併回原始 DataFrame
        df_featured = pd.merge(df_featured, group_agg, on=group_by_col, how='left')

        print("\n✅ 已成功將聚合特徵合併回主資料集。")
    else:
        print(f"⚠️ 在配置中定義的數值欄位不存在於資料中，跳過聚合步驟。")
else:
    print(f"⚠️ 用於分組的欄位 '{group_by_col}' 不存在，跳過此步驟。")
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：我們為每個 `pclass` 的乘客，都新增了其所在艙等的「平均票價」、「票價標準差」、「最高年齡」和「最低年齡」等特徵。
> *   **Why (思考)**：這為模型提供了強大的上下文資訊。例如，模型不僅知道某位乘客的個人票價，還知道這個票價在他所屬的群體中處於什麼水平，這可能比單純的個人票價更有預測力。

## 🚀 步驟 3：分解特徵 (Decomposing Features)

與組合特徵相反，有時將一個複雜的特徵拆解成多個更簡單的特徵會更有用。最典型的例子就是處理**日期時間**。

**【THINK】領航員引導式提問**
> 你的資料中是否有日期、時間或地址等複雜的複合型特徵？將它們分解開來，往往能發現隱藏的週期性或規律。

**【CODE】執行程式碼**
> 如果你的資料中有日期時間欄位，下面的程式碼將演示如何从中提取出大量有用的新特徵。

```python
# --- 使用者需修改的區域 ---
# 選擇一個日期時間欄位進行分解
datetime_col = 'date' # <-- 請替換成你的日期時間欄位名
# -------------------------

if datetime_col in df_featured.columns:
    # 確保該欄位是 datetime 型態
    df_featured[datetime_col] = pd.to_datetime(df_featured[datetime_col], errors='coerce')

    # 刪除因轉換失敗而變為 NaT 的行
    df_featured.dropna(subset=[datetime_col], inplace=True)

    print(f"--- 從 '{datetime_col}' 分解出時間特徵 ---")
    df_featured['year'] = df_featured[datetime_col].dt.year
    df_featured['month'] = df_featured[datetime_col].dt.month
    df_featured['day'] = df_featured[datetime_col].dt.day
    df_featured['hour'] = df_featured[datetime_col].dt.hour
    df_featured['dayofweek'] = df_featured[datetime_col].dt.dayofweek # 星期一=0, 星期日=6
    df_featured['is_weekend'] = (df_featured['dayofweek'] >= 5).astype(int)

    print("✅ 已成功分解時間特徵。")
    display(df_featured[['year', 'month', 'day', 'hour', 'dayofweek', 'is_weekend']].head())
else:
    print(f"⚠️ 未找到日期時間欄位 '{datetime_col}'，跳過此步驟。")

```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：一個簡單的時間戳 `2024-07-15 10:00:00` 被我們分解成了 `年`、`月`、`日`、`小時`、`星期幾`、`是否週末` 等多個維度的資訊。
> *   **Why (思考)**：模型無法直接理解 `2024-07-15` 和 `2023-07-15` 的關係，但它可以輕易地從 `year` 特徵中學到「年份」這個概念。同樣，`is_weekend` 這個特徵直接告訴了模型「週末」這個重要的週期性資訊，這對預測很多行為（如購物、出行）都至關重要。
