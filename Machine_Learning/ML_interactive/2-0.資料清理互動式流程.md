## 🚀 步驟 1：重複資料處理 (Handling Duplicates)

重複的資料會讓模型產生偏誤，就像讓一位學生重複做同一份考卷來評估他的能力一樣，結果會失真。我們必須找出並移除它們。

**【CODE】執行程式碼**
> 首先，讓我們檢查是否存在完全重複的資料列。

```python
# 為了方便操作，我們先複製一份原始 DataFrame
df_cleaned = df.copy()

# 檢查重複資料的數量
duplicate_rows = df_cleaned.duplicated().sum()
print(f"資料集中發現 {duplicate_rows} 筆完全重複的資料列。")

if duplicate_rows > 0:
    # 顯示所有重複的資料（包括第一次出現的）
    print("\n--- 以下是所有重複的資料列 ---")
    display(df_cleaned[df_cleaned.duplicated(keep=False)])

    # 移除重複資料，預設保留第一筆
    df_cleaned.drop_duplicates(inplace=True)
    print(f"\n✅ 已移除重複資料。清理後的資料維度為: {df_cleaned.shape}")
else:
    print("\n✅ 資料集中沒有發現重複列，非常乾淨！")
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：我們使用 `df.duplicated().sum()` 快速計算出重複記錄的數量。`keep=False` 參數可以幫助我們把所有相關的重複項都顯示出來，方便核對。
> *   **Why (思考)**：為何會出現重複資料？可能是資料收集過程中的錯誤，或是資料合併時的 bug。理解原因有助於從源頭改善資料品質。
> *   **How (行動)**：`df.drop_duplicates(inplace=True)` 是最直接的解決方案，它會修改 `df_cleaned` 本身，移除重複項。`inplace=True` 表示直接在原數據上修改，可以節省記憶體。

**【THINK】領航員引導式提問**
> 在某些情況下，我們只關心特定欄位的組合是否重複（例如，`使用者ID` 和 `訂單日期`）。`drop_duplicates` 有一個 `subset` 參數可以做到這一點。你的資料中，是否存在這類需要基於部分欄位來判斷的重複情況呢？

## 🚀 步驟 2：欄位命名與文字清理 (Standardizing Names & Text)

混亂的欄位名稱（大小寫混用、含空格）和不乾淨的文字（多餘的空白、奇怪的標點）是程式碼出錯和分析困難的常見原因。讓我們把它們一次性標準化。

**【CODE】執行程式碼**
> 以下程式碼會將所有欄位名稱轉為小寫並用底線 `_` 取代空格。同時，我們也會展示如何清理文字欄位。

```python
print("--- 原始欄位名稱 ---")
print(df_cleaned.columns.tolist())

# 1. 標準化欄位命名
df_cleaned.columns = df_cleaned.columns.str.lower().str.replace(' ', '_')

print("\n--- 標準化後的欄位名稱 ---")
print(df_cleaned.columns.tolist())
print("\n✅ 欄位名稱已標準化。")

# 2. 清理文字欄位 (以 'name' 欄位為例，如果存在的話)
# 假設我們有一個名為 'name' 的欄位需要清理
if 'name' in df_cleaned.columns:
    print("\n--- 清理 'name' 欄位範例 ---")
    # 清理前
    print("清理前範例:", df_cleaned['name'].iloc[0] if not df_cleaned.empty else "N/A")
    
    # 鏈式操作：1. 轉小寫 -> 2. 移除頭尾空白
    df_cleaned['name'] = df_cleaned['name'].str.lower().str.strip()
    
    # 清理後
    print("清理後範例:", df_cleaned['name'].iloc[0] if not df_cleaned.empty else "N/A")
    print("\n✅ 文字欄位清理完成。")
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：我們使用了 Pandas 的 `.str` 存取器，它可以讓我們對整個 Series 的每個字串進行快速操作，如 `.lower()`、`.replace()`、`.strip()`。
> *   **Why (思考)**：標準化的命名可以讓你後續用 `df.欄位名` 的方式輕鬆存取，而不用總是寫 `df['欄位 名']`，大大減少了出錯的機會。乾淨的文字則是後續進行自然語言處理（NLP）的基礎。
> *   **How (行動)**：你可以將上述清理文字欄位的範例程式碼，應用到你的資料中任何需要清理的 `object` 型態欄位上。

## 🚀 步驟 3：資料型態修正 (Correcting Data Types)

在 `1-0` 階段，我們透過 `df.info()` 檢查了資料型態。如果發現有欄位型態不符預期（例如，應為數字的 `price` 欄位被存為 `object`），現在就是修正它的時候。

**【CODE】執行程式碼**
> `pd.to_numeric` 和 `pd.to_datetime` 是我們處理這類問題的強大工具，尤其是當資料中混雜著無法轉換的髒數據時。

```python
print("--- 修正前的資料型態 ---")
df_cleaned.info(memory_usage=False)

# --- 使用者需修改的區域 ---
# 範例: 
# numeric_cols = ['age', 'fare']
# datetime_cols = ['order_date']
numeric_cols = []  # <-- 請填寫應為數值但目前不是的欄位
datetime_cols = [] # <-- 請填寫應為日期但目前不是的欄位
# -------------------------

# 轉換數值型態，並將無效值設為 NaN
for col in numeric_cols:
    if col in df_cleaned.columns:
        original_type = df_cleaned[col].dtype
        df_cleaned[col] = pd.to_numeric(df_cleaned[col], errors='coerce')
        print(f"\n✅ 欄位 '{col}' ({original_type} -> {df_cleaned[col].dtype}) 轉換完成。")
        # errors='coerce' 會將所有無法轉換的值（如文字'N/A'）變成缺失值 NaN，這在下一步處理缺失值時非常有用！

# 轉換日期型態
for col in datetime_cols:
    if col in df_cleaned.columns:
        original_type = df_cleaned[col].dtype
        df_cleaned[col] = pd.to_datetime(df_cleaned[col], errors='coerce')
        print(f"\n✅ 欄位 '{col}' ({original_type} -> {df_cleaned[col].dtype}) 轉換完成。")

print("\n--- 修正後的資料型態 ---")
df_cleaned.info(memory_usage=False)
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：再次檢視 `df.info()` 的輸出，確認目標欄位的 `Dtype` 是否已成功變更。
> *   **Why (思考)**：`errors='coerce'` 是一個關鍵參數。如果直接用 `.astype(int)`，只要欄位中有一個非數字字元，整個轉換就會失敗。而 `errors='coerce'` 則提供了更強的容錯能力，它會將問題數據標記為 `NaN`（缺失值），讓我們可以在下一個階段統一處理它們。
> *   **How (行動)**：請根據你在 `1-0` 的觀察，將需要轉換的欄位名稱填入 `numeric_cols` 和 `datetime_cols` 列表中並執行。

## 🚀 步驟 4：移除不相關或多餘的欄位 (Dropping Columns)

有些欄位對於我們的分析目標可能毫無幫助（如隨機ID），或是在清理後變得多餘。移除它們可以讓資料集更聚焦，並節省記憶體。

**【THINK】領航員引導式提問**
> 根據你的專案目標，審視一下目前所有的欄位。是否存在一些欄位，你認為它們對最終的預測或分析**完全沒有貢獻**？（例如：乘客姓名對預測生存率可能無用，但乘客ID更是絕對無用）。

**【CODE】執行程式碼**
> 請將你決定移除的欄位名稱填入 `columns_to_drop` 列表中。

```python
# --- 使用者需修改的區域 ---
# 範例: columns_to_drop = ['passengerid', 'ticket', 'cabin']
columns_to_drop = [] # <-- 請填寫要移除的欄位名稱
# -------------------------

# 檢查欄位是否存在於 DataFrame 中
existing_cols_to_drop = [col for col in columns_to_drop if col in df_cleaned.columns]

if existing_cols_to_drop:
    df_cleaned.drop(columns=existing_cols_to_drop, inplace=True)
    print(f"✅ 已成功移除以下欄位: {existing_cols_to_drop}")

```
