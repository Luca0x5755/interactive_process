## 🚀 步驟 1：理解兩種主要的縮放策略

在動手之前，我們需要理解兩種最主流的縮放方法：

1.  **標準化 (Standardization / Z-score Scaling)**
    *   **原理**: 將數據轉換為平均數為 0，標準差為 1 的分佈。
    *   **公式**: `(X - 平均數) / 標準差`
    *   **優點**: 對離群值 (Outliers) 較不敏感，是**最常用、最穩健**的縮放方法。
    *   **適用模型**: 適用於絕大多數演算法，特別是當你不確定數據分佈或存在離群值時。

2.  **歸一化 (Normalization / Min-Max Scaling)**
    *   **原理**: 將數據線性地縮放到一個固定的區間，通常是 [0, 1]。
    *   **公式**: `(X - 最小值) / (最大值 - 最小值)`
    *   **優點**: 能確保所有特徵都在同一範圍內，對於神經網路等演算法效果較好。
    *   **缺點**: 對離群值非常敏感。一個極大的離群值會把其他所有數據點都「壓縮」到一個很小的區間內。

**【THINK】領航員引導式提問**
> 根據你的數據情況，哪種方法更適合你？
> *   我的數據中是否存在我不想讓其過度影響縮放結果的**離群值**？(若是，**標準化**更適合)
> *   我的演算法（如神經網路）是否明確要求輸入特徵在 **[0, 1]** 範圍內？(若是，**歸一化**更適合)
> *   如果不確定，選擇**標準化**通常是一個安全且有效的起點。

## 🚀 步驟 2：執行特徵縮放與視覺化

現在，讓我們將理論付諸實踐，並透過視覺化來觀察縮放前後的變化。

**【CODE】執行程式碼**
> 下面的程式碼將使用 `scikit-learn` 的 `StandardScaler` 和 `MinMaxScaler` 來處理數據。

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler
import seaborn as sns
import matplotlib.pyplot as plt

# 創建一個副本以進行操作
df_scaled = df_encoded.copy()

# 找出所有數值型欄位進行縮放
numerical_cols = df_scaled.select_dtypes(include=np.number).columns.tolist()

if numerical_cols:
    # --- 使用者需修改的區域 ---
    # 選擇你的縮放策略: 'standard' 或 'minmax'
    scaling_strategy = 'standard' # <-- 推薦從 'standard' 開始
    # -------------------------

    print(f"--- 選擇的策略: {scaling_strategy} ---")

    if scaling_strategy == 'standard':
        scaler = StandardScaler()
    elif scaling_strategy == 'minmax':
        scaler = MinMaxScaler()
    else:
        raise ValueError("策略必須是 'standard' 或 'minmax'")

    # 為了視覺化，我們先畫出縮放前的分佈 (以頭兩個數值特徵為例)
    plt.figure(figsize=(12, 5))
    plt.subplot(1, 2, 1)
    sns.kdeplot(df_scaled[numerical_cols[0]], fill=True, label='Original')
    sns.kdeplot(df_scaled[numerical_cols[1]], fill=True, label='Original')
    plt.title("縮放前 (Before Scaling)")
    plt.legend()

    # 應用縮放器
    df_scaled[numerical_cols] = scaler.fit_transform(df_scaled[numerical_cols])

    # 畫出縮放後的分佈
    plt.subplot(1, 2, 2)
    sns.kdeplot(df_scaled[numerical_cols[0]], fill=True, label='Scaled')
    sns.kdeplot(df_scaled[numerical_cols[1]], fill=True, label='Scaled')
    plt.title("縮放後 (After Scaling)")
    plt.legend()
    plt.tight_layout()
    plt.show()

    print("\n✅ 所有數值特徵已成功縮放。")
    print("--- 縮放後的資料預覽 ---")
    display(df_scaled.head())
else:
    print("✅ 資料集中沒有找到需要縮放的數值特徵。")

```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：觀察左右兩邊的圖。左圖中，不同特徵的曲線可能分佈在 x 軸的不同區間，且形狀各異。右圖中，它們都被調整到了相似的尺度上。如果使用 `StandardScaler`，它們的中心會對齊在 0 附近；如果使用 `MinMaxScaler`，它們會被壓縮到 [0, 1] 區間內。
> *   **Why (思考)**：重要的是，特徵縮放**不會改變數據的分佈形狀**，它只改變數據的**尺度**。原本是偏態的數據，縮放後依然是偏態的。
> *   **How (行動)**：在真實專案中，有一個至關重要的原則——**防止數據洩漏 (Data Leakage)**。你應該只在**訓練集 (Training Set)** 上 `fit` 縮放器（即計算平均數、標準差等），然後用同一個 `fit` 好的縮放器去 `transform` 你的**訓練集、驗證集和測試集**。這樣可以確保所有數據都經過了完全相同的轉換，模擬了模型在真實世界中處理未知新數據的情境。
