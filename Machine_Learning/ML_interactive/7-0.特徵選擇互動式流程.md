## 🚀 步驟 1：過濾法 (Filter Method) - 快速的統計篩選

**過濾法**獨立於任何模型，它根據特徵與目標之間的統計關係來打分，快速篩掉無關的特徵。它計算速度極快，是特徵初篩的絕佳工具。

**【CODE】執行程式碼**
> 我們將使用 `SelectKBest` 搭配 `f_classif` (ANOVA F-test)，它會計算每個特徵與目標之間的 F-分數，我們從中選出分數最高的 K 個特徵。

```python
from sklearn.feature_selection import SelectKBest, f_classif

if X is not None:
    # --- 使用者需修改的區域 ---
    K = 5 # 選擇分數最高的 5 個特徵
    # -------------------------

    # 初始化選擇器
    selector_filter = SelectKBest(score_func=f_classif, k=K)

    # 在訓練集上擬合和轉換
    X_train_filter = selector_filter.fit_transform(X_train, y_train)
    X_test_filter = selector_filter.transform(X_test)

    # 獲取被選中的特徵名稱
    selected_features_filter = X_train.columns[selector_filter.get_support()]

    print(f"--- 過濾法 (SelectKBest) 選擇了 {len(selected_features_filter)} 個特徵 ---")
    print(selected_features_filter.tolist())

    # 顯示各特徵的分數
    scores = pd.DataFrame({
        'Feature': X_train.columns,
        'F-Score': selector_filter.scores_,
        'P-Value': selector_filter.pvalues_
    }).sort_values(by='F-Score', ascending=False)
    print("\n各特徵的 F-分數 (越高越好) 與 P-值 (越低越好):")
    display(scores.round(4))
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：我們得到了一個根據 F-分數排序的特徵列表。分數越高，代表該特徵與目標的關聯性越強。
> *   **Why (思考)**：過濾法非常高效，但它的主要缺點是**忽略了特徵之間的交互作用**。它只是單獨評估每個特徵，而沒有考慮它們組合起來可能產生的效果。

---

## 🚀 步驟 2：包裹法 (Wrapper Method) - 追求極致效能

**包裹法**將特徵選擇視為一個搜尋問題。它用一個你指定的模型，反覆訓練並評估不同特徵組合的表現，從而「包裹」住模型來找到最佳特徵子集。它效果通常很好，但計算成本高昂。

**【CODE】執行程式碼**
> 我們將使用 **RFECV (遞歸特徵消除與交叉驗證)**。它會從所有特徵開始，不斷地移除最不重要的特徵，並透過交叉驗證自動找到最佳的特徵數量。

```python
from sklearn.feature_selection import RFECV
from sklearn.linear_model import LogisticRegression

if X is not None:
    print("--- 正在執行包裹法 (RFECV)，這可能需要一些時間... ---")
    # 選擇一個模型作為評估器
    model = LogisticRegression(solver='liblinear')

    # 初始化 RFECV
    selector_wrapper = RFECV(estimator=model, step=1, cv=5, scoring='accuracy')

    # 擬合選擇器
    selector_wrapper.fit(X_train, y_train)

    # 獲取被選中的特徵
    selected_features_wrapper = X_train.columns[selector_wrapper.support_]

    print(f"\nRFECV 完成！它找到的最佳特徵數量為: {selector_wrapper.n_features_}")
    print("被選中的特徵是:")
    print(selected_features_wrapper.tolist())

    # 應用到數據集
    X_train_wrapper = selector_wrapper.transform(X_train)
    X_test_wrapper = selector_wrapper.transform(X_test)
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：RFECV 自動為我們確定了最佳的特徵數量和具體是哪些特徵。
> *   **Why (思考)**：包裹法直接以最終模型的性能為導向，因此能考慮到特徵間的交互關係，選出的特徵組合通常對該特定模型最優。但這也意味著如果更換模型，可能需要重新進行選擇。

## 🚀 步驟 3：嵌入法 (Embedded Method) - 效率與效果的平衡

**嵌入法**將特徵選擇的過程，融入到模型訓練中。模型在學習的同時，會自動為特徵賦予權重或重要性，從而篩選掉不重要的特徵。它是效率與效果的完美結合。

**【CODE】執行程式碼**
> 我們將使用**基於樹的模型（隨機森林）**。在訓練後，它可以提供每個特徵的「重要性分數」，我們據此進行篩選。

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.feature_selection import SelectFromModel

if X is not None:
    print("--- 正在執行嵌入法 (Random Forest Feature Importance)... ---")
    # 訓練一個隨機森林模型
    model_embedded = RandomForestClassifier(n_estimators=100, random_state=42)
    model_embedded.fit(X_train, y_train)

    # 根據特徵重要性進行選擇
    # threshold='median' 表示選擇重要性高於中位數的特徵
    selector_embedded = SelectFromModel(model_embedded, prefit=True, threshold='median')

    # 獲取被選中的特徵
    selected_features_embedded = X_train.columns[selector_embedded.get_support()]
    print(f"\n嵌入法選擇了 {len(selected_features_embedded)} 個特徵:")
    print(selected_features_embedded.tolist())

    # 視覺化特徵重要性
    importances = pd.DataFrame({
        'Feature': X_train.columns,
        'Importance': model_embedded.feature_importances_
    }).sort_values(by='Importance', ascending=False)

    plt.figure(figsize=(10, 6))
    sns.barplot(x='Importance', y='Feature', data=importances)
    plt.title('隨機森林計算的特徵重要性')
    plt.show()

    # 應用到數據集
    X_train_embedded = selector_embedded.transform(X_train)
    X_test_embedded = selector_embedded.transform(X_test)
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：我們得到了一張直觀的圖表，清晰地顯示了每個特徵對模型的貢獻度。`sex` 和 `fare` 等特徵顯示出較高的重要性。
> *   **Why (思考)**：嵌入法在一次模型訓練中就完成了特徵選擇，效率遠高於包裹法，同時也考慮了特徵間的交互（因為模型本身就會考慮），是實務上非常流行的方法。

**【發現總結 (Key Findings)】**
> | 方法類型 | 優點 | 缺點 | 適用場景 |
> | :--- | :--- | :--- | :--- |
> | **過濾法** | 計算速度極快，模型無關 | 忽略特徵交互 | 資料初篩，快速建立基準 |
> | **包裹法** | 效果通常最好，考慮交互 | 計算成本極高，易過擬合 | 特徵量不大，追求極致性能 |
> | **嵌入法** | 效果與效率的良好平衡 | 與特定模型綁定 | 大多數情況下的首選 |
