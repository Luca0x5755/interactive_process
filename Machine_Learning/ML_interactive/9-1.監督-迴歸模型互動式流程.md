## 🚀 步驟 1：切分訓練集與測試集 (Train-Test Split)

**【CODE】執行程式碼**

## 🚀 步驟 2：選擇並訓練你的迴歸模型

與分類任務一樣，迴歸模型也種類繁多。我們從三個經典模型開始。

1.  **線性迴歸 (Linear Regression)**
    *   **特點**: 快速、簡單、可解釋性強。是理解迴歸問題的基石。

2.  **隨機森林迴歸 (Random Forest Regressor)**
    *   **特點**: 由多棵決策樹組成的集成模型，通常準確率高，且不易過擬合。

3.  **梯度提升迴歸 (Gradient Boosting Regressor)**
    *   **特點**: 另一種強大的集成模型，循序漸進地修正錯誤，通常能達到極高的精度。

**【CODE】執行程式碼**
> 我們將一次性訓練這三個模型，並比較它們的性能。

```python
from sklearn.linear_model import LinearRegression
from sklearn.ensemble import RandomForestRegressor, GradientBoostingRegressor
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
import numpy as np

if X_train is not None:
    models = {
        "Linear Regression": LinearRegression(),
        "Random Forest": RandomForestRegressor(random_state=42),
        "Gradient Boosting": GradientBoostingRegressor(random_state=42)
    }

    results = {}

    for name, model in models.items():
        print(f"--- 正在訓練模型: {name} ---")
        model.fit(X_train, y_train)
        y_pred = model.predict(X_test)
        
        # 計算評估指標
        mae = mean_absolute_error(y_test, y_pred)
        rmse = np.sqrt(mean_squared_error(y_test, y_pred))
        r2 = r2_score(y_test, y_pred)
        results[name] = {'MAE': mae, 'RMSE': rmse, 'R2': r2, 'Predictions': y_pred}
        print(f"✅ {name} 訓練與評估完成。")

```

**【ANALYSIS】領航員深度解析**
> *   **MAE (平均絕對誤差)**：代表模型預測的平均誤差大小。例如，MAE 為 5000，意味著模型預測時，平均會偏離真實值 5000。單位與你的目標變數相同，非常直觀。
> *   **RMSE (均方根誤差)**：與 MAE 類似，但它對較大的誤差給予更高的權重。因此，如果 RMSE 遠大於 MAE，可能意味著你的模型在某些點上犯了很大的錯誤。
> *   **R² (決定係數)**：衡量模型解釋力的指標。越接近 1，表示模型能解釋越多目標變數的變異性，擬合效果越好。一個 R² 為負數的模型，說明它的表現比直接預測平均數還要差。

## 🚀 步驟 3：視覺化診斷最佳模型

數字是抽象的，圖表是直觀的。讓我們畫出最佳模型的預測結果，看看它到底做得怎麼樣。

**【CODE】執行程式碼**
> 我們將繪製一個**預測值 vs. 真實值**的散點圖。一個完美的模型，所有的點都應該落在 45 度的對角線上。

```python
import matplotlib.pyplot as plt
import seaborn as sns

if 'best_model_name' in locals():
    plt.figure(figsize=(8, 8))
    
    best_predictions = results[best_model_name]['Predictions']
    
    # 繪製散點圖
    plt.scatter(y_test, best_predictions, alpha=0.5)
    
    # 繪製完美的對角線
    p1 = max(max(y_test), max(best_predictions))
    p2 = min(min(y_test), min(best_predictions))
    plt.plot([p1, p2], [p1, p2], 'r--', lw=2)
    
    plt.title(f'{best_model_name}: 真實值 vs. 預測值')
    plt.xlabel('真實值 (Actual Values)')
    plt.ylabel('預測值 (Predicted Values)')
    plt.axis('equal')
    plt.grid(True)
    plt.show()
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：散點圖中的點是否緊密地圍繞著紅色的虛線分佈？
> *   **Why (思考)**：如果點的分佈很鬆散，或者呈現出某種模式（例如，在數值高的地方預測偏低），這都說明模型在某些方面存在系統性的偏差。
> *   **How (行動)**：觀察那些離對角線特別遠的點，它們是模型預測最不準確的樣本。分析這些樣本的特徵，可能會給你帶來關於如何進一步改進模型的靈感。
