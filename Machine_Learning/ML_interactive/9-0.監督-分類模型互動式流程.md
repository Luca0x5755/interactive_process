## 🚀 步驟 1：切分訓練集與測試集 (Train-Test Split)

這是模型訓練的黃金準則：**絕對不可以用來訓練模型的資料去評估模型的好壞**。我們必須留出一部分「從未見過」的資料（測試集）來模擬模型在真實世界中的表現。

**【CODE】執行程式碼**
> 我們將使用 `train_test_split` 函數。`stratify=y` 是一個很重要的參數，它能確保切分後，訓練集和測試集中的各個類別比例與原始資料集保持一致。

```python
from sklearn.model_selection import train_test_split

# 假設 X_selected 和 y 已經從 7-0 章節準備好
if 'X_selected' in locals() and 'y' in locals():
    X_train, X_test, y_train, y_test = train_test_split(
        X_selected, 
        y, 
        test_size=0.2,    # 20% 的資料作為測試集
        random_state=42,  # 設置隨機種子以確保結果可重現
        stratify=y        # 依據 y 的類別比例進行分層抽樣
    )
    print("✅ 資料切分完成。")
    print(f"訓練集維度 (X_train): {X_train.shape}")
    print(f"測試集維度 (X_test): {X_test.shape}")
else:
    print("❌ 錯誤：找不到 X_selected 或 y。請先執行 7-0 特徵選擇流程。")
    X_train, X_test, y_train, y_test = [None]*4
```

## 🚀 步驟 2：選擇你的分類模型

世界上沒有萬能的模型。我們從三個經典且具代表性的模型開始，它們各有千秋。

1.  **邏輯斯迴歸 (Logistic Regression)**
    *   **特點**: 快速、簡單、可解釋性強。是線性模型，適合作為基準線。
    *   **適用**: 需要快速驗證想法，或當特徵與目標關係較簡單時。

2.  **決策樹 (Decision Tree)**
    *   **特點**: 直觀，像流程圖一樣易於理解。能捕捉非線性關係。
    *   **缺點**: 容易過擬合（在訓練集上表現太好，在新數據上表現差）。

3.  **隨機森林 (Random Forest)**
    *   **特點**: 由多棵決策樹組成的「集成模型」。通常準確率高，且不易過擬合，非常穩健。
    *   **缺點**: 可解釋性較差（黑盒子），計算成本較高。

**【THINK】領航員引導式提問**
> 你想先嘗試哪個模型？對於初學者，建議從**邏輯斯迴歸**開始建立一個基準，然後用**隨機森林**來追求更高的性能。

**【CODE】執行程式碼**
> `scikit-learn` 的 API 設計得非常好，訓練任何模型都遵循同樣的 `fit-predict` 模式。你可以透過註解/取消註解來選擇不同的模型。

```python
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

if X_train is not None:
    # --- 使用者需修改的區域 ---
    # 選擇你的模型，可以取消註解來嘗試不同的模型
    models = {
        "Logistic Regression": LogisticRegression(random_state=42),
        "Decision Tree": DecisionTreeClassifier(random_state=42),
        "Random Forest": RandomForestClassifier(random_state=42)
    }
    # -------------------------

    results = {}

    for name, model in models.items():
        print(f"--- 正在訓練模型: {name} ---")
        
        # 1. 訓練模型 (fit the model)
        model.fit(X_train, y_train)
        
        # 2. 對測試集進行預測
        y_pred = model.predict(X_test)
        
        # 3. 計算準確率
        accuracy = accuracy_score(y_test, y_pred)
        results[name] = accuracy
        
        print(f"✅ {name} 訓練與評估完成。")

    print("\n--- 所有模型在測試集上的準確率 --- ")
    for name, acc in results.items():
        print(f"{name}: {acc:.4f}")

    # 找出表現最好的模型
    best_model_name = max(results, key=results.get)
    print(f"\n🏆 表現最佳的模型是: {best_model_name}，準確率為 {results[best_model_name]:.4f}")

```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：我們快速地訓練了三個不同的模型，並得到了它們在測試集上的準確率。通常，隨機森林的表現會比較突出。
> *   **Why (思考)**：為什麼隨機森林通常更好？因為它結合了多個不同決策樹的智慧（集成學習），減少了單一決策樹因偶然性而犯錯的風險，從而提高了模型的穩定性和泛化能力。
> *   **How (行動)**：這個框架讓你可以輕鬆地加入更多模型進行比較，例如 `SVM`, `GradientBoostingClassifier` 等。

## 🚀 步驟 3：深入思考「準確率」

準確率 (Accuracy) 是最直觀的指標，但它也可能是最具誤導性的指標之一。

**【THINK】領航員引導式提問**
> 想像一個場景：在 100 個病人中，有 99 個是健康的，1 個是癌症患者。一個「笨模型」永遠只預測「健康」，它的準確率高達 99%！但這個模型有任何實際價值嗎？
>
> **完全沒有！** 因為它完全錯過了我們最關心的那個癌症病例。
>
> 這就是**類別不平衡 (Imbalanced Classes)** 問題。在這種情況下，我們需要更精細的評估工具來判斷模型的好壞。
