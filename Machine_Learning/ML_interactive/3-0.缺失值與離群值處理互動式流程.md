## 🚀 步驟 1：缺失值診斷與視覺化 (Missing Value Diagnosis)

在動手填補之前，我們必須先成為一名「數據偵探」，全面了解缺失值的狀況。

**【CODE】執行程式碼**
> 這段程式碼會計算每個欄位的缺失值數量與比例，並使用 `missingno` 套件將其視覺化，讓我們對缺失模式一目了然。

```python
import missingno as msno
import matplotlib.pyplot as plt
import seaborn as sns

# 計算缺失值的數量與比例
missing_values = df_cleaned.isnull().sum()
missing_percentage = (missing_values / len(df_cleaned)) * 100
missing_info = pd.DataFrame({
    'Missing Values': missing_values,
    'Percentage (%)': missing_percentage
}).sort_values(by='Percentage (%)', ascending=False)

missing_info = missing_info[missing_info['Missing Values'] > 0]

if not missing_info.empty:
    print("--- 缺失值報告 ---")
    display(missing_info)

    # 使用 missingno 進行視覺化
    print("\n--- 缺失值視覺化分析 ---")
    msno.matrix(df_cleaned)
    plt.title('msno.matrix(): 樣本缺失值模式矩陣圖', fontsize=16)
    plt.show()

    msno.bar(df_cleaned)
    plt.title('msno.bar(): 欄位資料完整度條形圖', fontsize=16)
    plt.show()
else:
    print("✅ 恭喜！資料集中沒有發現任何缺失值。可以跳至步驟3。")
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：

>     *   **matrix 圖**: 白色線條代表缺失。它可以揭示缺失是否具有隨機性。如果某些行的白色線條總是一起出現，可能代表這些樣本有共同的問題。
>     *   **bar 圖**: 從整體上快速看出哪些欄位的資料最不完整。
> *   **Why (思考)**：缺失比例極高的欄位（如 `cabin`），其資訊價值可能已經很低。而缺失比例低的欄位（如 `age`），我們則有較大的信心去填補它。

## 🚀 步驟 2：缺失值處理策略 (Handling Missing Values)

現在，我們要根據診斷結果，選擇最合適的「療法」。

**【THINK】領航員引導式提問**
> 根據你的缺失值報告和業務理解，你打算如何處理這些缺失的欄位？
> *   **策略1：直接刪除** (適用於缺失比例極高，或該欄位/列不重要的情況)。
> *   **策略2：統計量填補** (最常用，用中位數/眾數等填充)。
> *   **策略3：常數填補** (當缺失本身有意義時，如用 'Unknown' 或 0 填充)。

**【CODE】執行程式碼**
> 請根據你的策略，修改並執行以下程式碼。我已經為你準備了最常見的填補方法。

```python
# 創建一個副本以進行操作
df_processed = df_cleaned.copy()

# --- 使用者需修改的區域 ---

# 策略 1: 刪除缺失比例過高的欄位 (範例：刪除缺失超過 50% 的欄位)
cols_to_drop = missing_info[missing_info['Percentage (%)'] > 50].index.tolist()
if cols_to_drop:
    df_processed.drop(columns=cols_to_drop, inplace=True)
    print(f"✅ 已刪除缺失比例過高的欄位: {cols_to_drop}")

# 策略 2: 填補數值型欄位 (用中位數 'median' 或平均值 'mean')
numerical_cols_to_fill = [] # <-- 請從缺失值報告中，挑選要用中位數填補的【數值型】欄位
for col in numerical_cols_to_fill:
    if col in df_processed.columns:
        median_val = df_processed[col].median()
        df_processed[col].fillna(median_val, inplace=True)
        print(f"✅ 數值欄位 '{col}' 的缺失值已用中位數 ({median_val}) 填補。")

# 策略 3: 填補類別型欄位 (用眾數 'mode')
categorical_cols_to_fill = [] # <-- 請從缺失值報告中，挑選要用眾數填補的【類別型】欄位
for col in categorical_cols_to_fill:
    if col in df_processed.columns:
        mode_val = df_processed[col].mode()[0]
        df_processed[col].fillna(mode_val, inplace=True)
        print(f"✅ 類別欄位 '{col}' 的缺失值已用眾數 ('{mode_val}') 填補。")

# -------------------------

# 最後再次檢查是否還有缺失值
print("\n--- 處理後的缺失值報告 ---")
if df_processed.isnull().sum().sum() == 0:
    print("✅ 所有已規劃的缺失值都已成功處理！")
else:
    print("仍有缺失值的欄位：")
    display(df_processed.isnull().sum()[df_processed.isnull().sum() > 0])
```

**【ANALYSIS】領航員深度解析**
> *   **Why (思考)**：為什麼數值型常用**中位數 (median)** 而非平均值 (mean)？因為中位數對**離群值**不敏感。想像一下，一個班級的平均月薪可能會因為一位超級富豪的存在而被大幅拉高，但中位數則不受影響。類別型資料則自然地使用出現最頻繁的**眾數 (mode)** 來填補。
> *   **How (行動)**：將你在缺失值報告中看到的欄位，根據其資料型態（數值/類別）填入對應的列表中執行即可。

## 🚀 步驟 3：離群值偵測 (Outlier Detection)

離群值是那些遠離大部分資料點的「極端份子」。它們可能是真實的極端事件，也可能是資料紀錄錯誤。**箱型圖 (Box Plot)** 是偵測它們的利器。

**【CODE】執行程式碼**
> 這段程式碼會為所有數值型欄位繪製箱型圖，並用 IQR 法則計算出離群值的邊界。

```python
# 選擇所有數值型態的欄位
numerical_features = df_processed.select_dtypes(include=np.number).columns.tolist()

# 繪製每個數值特徵的箱型圖
if numerical_features:
    print("--- 數值特徵離群值檢視 (箱型圖) ---")
    plt.figure(figsize=(15, 5 * ((len(numerical_features) - 1) // 3 + 1)))
    for i, col in enumerate(numerical_features, 1):
        plt.subplot((len(numerical_features) - 1) // 3 + 1, 3, i)
        sns.boxplot(y=df_processed[col])
        plt.title(col)
    plt.tight_layout()
    plt.show()

    # 使用 IQR 法則進行統計偵測
    print("\n--- 使用「IQR 法」進行統計偵測 ---")
    for col in numerical_features:
        Q1 = df_processed[col].quantile(0.25)
        Q3 = df_processed[col].quantile(0.75)
        IQR = Q3 - Q1
        lower_bound = Q1 - 1.5 * IQR
        upper_bound = Q3 + 1.5 * IQR

        outliers = df_processed[(df_processed[col] < lower_bound) | (df_processed[col] > upper_bound)]

        print(f"\n欄位 '{col}':")
        print(f"  - 離群值邊界: < {lower_bound:.2f} 或 > {upper_bound:.2f}")
        if not outliers.empty:
            print(f"  - 偵測到 {len(outliers)} 個離群值。例如: {outliers[col].head(3).values}")
        else:
            print("  - 未偵測到離群值。")
else:
    print("資料集中沒有數值型特徵可供檢測離群值。")
```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：在箱型圖中，任何在「鬍鬚」(whiskers) 外面的點，都被視為離群值。下面的統計報告則量化了這個邊界。
> *   **Why (思考)**：IQR (四分位距) 法則是偵測離群值的穩健方法，因為它本身不受極端值的影響，比 Z-score 更常用。
> *   **How (行動)**：對於報告中偵測到離群值的欄位，我們需要結合業務知識來判斷如何處理它們。

## 🚀 步驟 4：離群值處理 (Handling Outliers)

**【THINK】領航員引導式提問**
> **處理離群值沒有標準答案，它高度依賴於你的業務理解。**
> *   如果這個離群值是**不可能發生**的（例如年齡為 200 歲），它很可能是個錯誤，可以直接移除或當作缺失值處理。
> *   如果它是**可能但極端**的（例如 CEO 的薪水遠高於其他人），移除它可能會損失重要資訊。此時，「縮尾」是個好方法。
> 
> 根據你的判斷，你打算如何處理偵測到的離群值？

**【CODE】執行程式碼**
> 這裡提供兩種最常見的處理方法：**條件篩選 (移除)** 和 **縮尾 (Capping/Winsorizing)**。

```python
# --- 使用者需修改的區域 ---

# 策略 1: 根據條件移除離群值 (適用於確定是錯誤的資料)
# 範例：移除 age > 100 的資料
if 'age' in df_processed.columns:
    original_rows = len(df_processed)
    df_processed = df_processed[df_processed['age'] <= 100]
    rows_removed = original_rows - len(df_processed)
    if rows_removed > 0:
        print(f"✅ 根據 'age' 欄位的條件，移除了 {rows_removed} 筆離群資料。")

# 策略 2: 縮尾處理 (將極端值替換為邊界值，推薦！)
# 範例：將 'fare' 欄位中超過上限的離群值，用上限值取代
col_to_cap = 'fare' # <-- 請填入你想處理的欄位
if col_to_cap in df_processed.columns:
    Q1 = df_processed[col_to_cap].quantile(0.25)
    Q3 = df_processed[col_to_cap].quantile(0.75)
    IQR = Q3 - Q1
    upper_bound = Q3 + 1.5 * IQR
    
    # 找出離群值的數量
    outlier_count = df_processed[df_processed[col_to_cap] > upper_bound].shape[0]
    if outlier_count > 0:
        # 用上限值替換離群值
        df_processed[col_to_cap] = np.where(df_processed[col_to_cap] > upper_bound, upper_bound, df_processed[col_to_cap])
        print(f"✅ 已對 '{col_to_cap}' 欄位進行縮尾處理，將 {outlier_count} 個超過 {upper_bound:.2f} 的值替換掉。")

# -------------------------

print(f"\n處理離群值後的資料維度為: {df_processed.shape}")
```
