## 🚀 步驟 3：敘述性統計分析 (Descriptive Stats)

接下來，我們深入**數值型**欄位，用統計數據來量化它們的分佈特性。

**【CODE】執行程式碼**
> `.describe()` 是我們探索數值特徵的瑞士刀。`.T` (Transpose) 則可以讓表格轉置，使其在垂直螢幕上更易於閱讀。

```python
print("--- 數值欄位敘述性統計 ---")
display(df.describe().T)
```

**【OUTPUT】預期輸出範例**
> ```text
> --- 數值欄位敘述性統計 ---
>              count       mean        std   min      25%     50%      75%      max
> PassengerId  891.0  446.000000  257.353842  1.00   223.50   446.0   668.50   891.00
> Survived     891.0    0.383838    0.486592  0.00     0.00     0.0     1.00     1.00
> Pclass       891.0    2.308642    0.836071  1.00     2.00     3.0     3.00     3.00
> Age          714.0   29.699118   14.526497  0.42    20.12    28.0    38.00    80.00
> SibSp        891.0    0.523008    1.102743  0.00     0.00     0.0     1.00     8.00
> Parch        891.0    0.273008    0.806057  0.00     0.00     0.0     0.00     6.00
> Fare         891.0   32.204208   49.693429  0.00     7.91    14.45    31.00   512.33
> ```

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：
>     *   **`count` (個數)**: 再次確認了 `Age` 欄位的缺失值數量 (891 - 714 = 177)。
>     *   **`mean` (平均數) vs `50%` (中位數)**: `Fare` (票價) 的平均數 (32.2) 遠大於中位數 (14.45)，這是一個強烈的信號。
>     *   **`std` (標準差)**: `Fare` 的標準差 (49.7) 非常大，幾乎是平均數的 1.5 倍。
>     *   **`min` (最小值) & `max` (最大值)**: `Age` 的最小值是 0.42 (嬰兒)，最大值是 80，看起來合理。但 `Fare` 的最大值高達 512，與第三四分位數 (`75%`) 的 31 相差懸殊。
> *   **Why (思考)**：
>     *   平均數和中位數的巨大差異，以及巨大的標準差，通常暗示著資料分佈存在**偏態 (Skewness)**。在 `Fare` 的例子中，這意味著大多數人的票價很低，但有少數極端高票價的乘客拉高了平均值。
>     *   最小值和最大值的極端值是否合理？如果 `Age` 出現 -5，或者 `Price` 出現負數，那它們就是**離群值 (Outliers)** 或資料錯誤。`Fare` 的 512 雖然極端，但在當時的艙等制度下可能是合理的，但仍需我們特別關注。
> *   **How (行動)**：
>     *   **請記下平均數和中位數差異懸殊的欄位**。這些欄位在後續建模時，可能需要進行對數轉換 (Log Transform) 等操作來緩解偏態。
>     *   **請記下最小值或最大值看起來不合常理的欄位**。這些是我們在 `3-0` 章節需要處理的**離群值**。

## 🚀 步驟 4：視覺化初步探索 (Initial Visualization)

數字是抽象的，圖表是直觀的。讓我們把統計發現轉化為視覺洞察。

**【CODE】執行程式碼**
> 這段程式碼會自動為所有數值欄位繪製**直方圖 (Histogram)**，讓我們能親眼看見它們的分佈形狀。

```python
# 選擇所有數值型態的欄位
numerical_features = df.select_dtypes(include=np.number).columns.tolist()

print("--- 數值特徵分佈直方圖 ---")
df[numerical_features].hist(bins=20, figsize=(15, 10), layout=(-1, 4), edgecolor='black')
plt.tight_layout() # 自動調整子圖間距
plt.show()
```

**【OUTPUT】預期輸出範例**
> 執行後，你會看到一組圖表。
> *   **Age** 的圖形可能像一個略微右偏的鐘形。
> *   **Fare** 的圖形則會像一個懸崖，數據絕大多數集中在左側，右邊有一條長長的尾巴。
> *   **Pclass** 或 **Survived** 的圖形則是幾個獨立的長條，因為它們是分類變數。

**【ANALYSIS】領航員深度解析**
> *   **What (觀察)**：每個數值特徵的分佈形狀是什麼？是對稱的鐘形（常態分佈）？還是數據偏向一邊（偏態分佈）？或者有多個峰值（多峰分佈）？
> *   **Why (思考)**：視覺化的結果是否印證了我們在步驟 3 的敘述性統計分析？`Fare` 的直方圖就完美解釋了為什麼它的平均數會遠大於中位數。多峰分佈可能暗示資料中存在幾個不同的子群體（例如，不同客戶群體的消費金額）。
> *   **How (行動)**：將這些視覺洞察記在心裡。一個欄位的分佈形狀，會直接影響我們後續選擇「缺失值填補策略」（用平均數還是中位數？）和「特徵縮放方法」的決策。
