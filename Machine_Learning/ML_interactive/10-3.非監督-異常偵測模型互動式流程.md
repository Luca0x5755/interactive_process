## ⚙️ 步驟 0：啟航前的準備 (Pre-flight Check)

我們將使用 `scikit-learn` 來實作三種主流的異常偵測演算法。請確保你的環境已準備就緒。

> **領航員提示**：異常偵測通常在數值型特徵集上進行。這裡我們假設你已準備好 `X_selected` 或 `X_scaled`。

**【CODE】執行程式碼**
> 為了專注於演算法比較，我們將生成一個包含正常點和異常點的模擬資料集。

```python
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.datasets import make_blobs

# 生成 200 個正常的資料點，分為兩群
X_normal, _ = make_blobs(n_samples=200, centers=2, cluster_std=1.0, random_state=42)
# 生成 20 個均勻分佈的異常點
X_outliers = np.random.uniform(low=-8, high=8, size=(20, 2))
# 合併成最終資料集
X = np.vstack([X_normal, X_outliers])

print(f"模擬資料已生成。原始維度: {X.shape}")

plt.figure(figsize=(8, 6))
plt.scatter(X[:, 0], X[:, 1], s=50, alpha=0.8)
plt.title('原始模擬資料分佈')
plt.show()
```

---

## 🚀 步驟 1：隔離森林 (Isolation Forest) - 高效的孤立者

**核心思想**: 異常點通常比正常點更容易被「孤立」。它透過隨機切割特徵來建樹，異常點因為稀少且遠離中心，平均只需要很少次切割就能被分離出來。

**優點**: 計算效率高，對高維數據表現好，是異常偵測的**首選基準模型**。

**【CODE】執行程式碼**
> `contamination` 參數是你對異常點比例的預估，這是模型唯一的超參數。

```python
from sklearn.ensemble import IsolationForest

# 初始化模型，假設我們預估有 10% 的異常點
iso_forest = IsolationForest(contamination=0.1, random_state=42)
y_pred_iso = iso_forest.fit_predict(X)

# 視覺化結果 (-1 為異常, 1 為正常)
plt.figure(figsize=(8, 6))
sns.scatterplot(x=X[:, 0], y=X[:, 1], hue=y_pred_iso, palette={1: 'blue', -1: 'red'}, s=50, alpha=0.8)
plt.title('Isolation Forest 異常偵測結果')
plt.legend(title='Prediction', labels=['Anomaly', 'Normal'])
plt.show()
```

---

## 🚀 步驟 2：局部異常因子 (LOF) - 關注局部密度

**核心思想**: 異常點的「局部密度」會顯著低於其鄰近點。它不看全局，只關心一個點和它周圍鄰居的密度對比。

**優點**: 能處理不同密度的資料群集，對局部異常的偵測非常敏感。
**缺點**: 計算複雜度較高，速度較慢。

**【CODE】執行程式碼**

```python
from sklearn.neighbors import LocalOutlierFactor

# n_neighbors 是計算局部密度時所考慮的鄰居數量
lof = LocalOutlierFactor(n_neighbors=20, contamination=0.1)
y_pred_lof = lof.fit_predict(X)

# 視覺化結果
plt.figure(figsize=(8, 6))
sns.scatterplot(x=X[:, 0], y=X[:, 1], hue=y_pred_lof, palette={1: 'blue', -1: 'red'}, s=50, alpha=0.8)
plt.title('Local Outlier Factor (LOF) 異常偵測結果')
plt.legend(title='Prediction', labels=['Anomaly', 'Normal'])
plt.show()
```

---

## 🚀 步驟 3：單類支持向量機 (One-Class SVM) - 學習正常邊界

**核心思想**: 傳統 SVM 是找一條線「分開」兩類點，而 One-Class SVM 是找一條線「包住」單一類別的點（即正常點）。所有在這條邊界之外的點，都被視為異常。

**優點**: 能學習複雜的非線性邊界。
**缺點**: 對超參數（特別是 `nu`）的選擇敏感，訓練速度較慢。

**【CODE】執行程式碼**
> `nu` 參數可以直觀地理解為你預估的異常點比例。

```python
from sklearn.svm import OneClassSVM

# nu 應設為預期的異常點比例
one_class_svm = OneClassSVM(nu=0.1)
y_pred_svm = one_class_svm.fit_predict(X)

# 視覺化結果
plt.figure(figsize=(8, 6))
sns.scatterplot(x=X[:, 0], y=X[:, 1], hue=y_pred_svm, palette={1: 'blue', -1: 'red'}, s=50, alpha=0.8)
plt.title('One-Class SVM 異常偵測結果')
plt.legend(title='Prediction', labels=['Anomaly', 'Normal'])
plt.show()
```
