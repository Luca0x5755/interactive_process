# 10-1. 非監督式學習：降維模型 (Dimensionality Reduction)

---

## 🎯 本章節任務與航行目標 (Mission & Objective)

**你好！我是「ML專案領航員」。**

在處理現代資料集時，我們常會遇到**維度災難 (Curse of Dimensionality)**——即特徵的數量（維度）非常多。高維度資料不僅會讓模型訓練變慢，還可能因包含無關或冗餘的資訊而降低模型效能。

*   **核心任務 (The "What")**: 在盡可能保留原始資料結構與資訊的前提下，用一組數量更少的新特徵來表示原始資料。
*   **最終目標 (The "Why")**: 加速模型訓練、壓縮數據、去除噪聲，以及將高維資料轉換為2D/3D圖表以便我們用肉眼觀察其結構。

準備好為你的資料集進行「瘦身」和「提純」了嗎？

## ⚙️ 步驟 0：啟航前的準備 (Pre-flight Check)

我們將使用 `scikit-learn` 來實作 PCA 和 t-SNE，並引入一個更現代化的 `umap` 函式庫。

**【ACTION】安裝函式庫**
> 如果你尚未安裝 `umap-learn`，請執行以下指令。

```bash
pip install umap-learn
```

> **領航員提示**：降維通常在數值型特徵集上進行。這裡我們假設你已準備好 `X_selected` 或 `X_scaled`。

**【CODE】執行程式碼**
> 為了專注於演算法比較，我們將使用 scikit-learn 內建的、經典的手寫數字資料集。它有 64 個維度（8x8像素），非常適合用來展示降維效果。

```python
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler

# 載入資料
digits = load_digits()
X = digits.data
y = digits.target

# 標準化是PCA等演算法的重要前置步驟
X_scaled = StandardScaler().fit_transform(X)

print(f"手寫數字資料集已載入並標準化。原始維度: {X_scaled.shape}")
```

---

## 🚀 步驟 1：主成分分析 (PCA) - 線性降維

**PCA** 是最經典的線性降維方法。它旨在找到資料中**變異最大**的方向，並將資料投影到這些方向（稱為主成分）上。

**【CODE】執行程式碼：如何決定降維到幾維？**
> 我們先不降維，而是計算所有主成分能解釋的「變異率」，並繪製「累計解釋變異率」曲線。一個常見的法則是，選擇能解釋 **95%** 變異的最小主成分數。

```python
from sklearn.decomposition import PCA
import numpy as np

pca_full = PCA(random_state=42).fit(X_scaled)

plt.figure(figsize=(10, 6))
plt.plot(np.cumsum(pca_full.explained_variance_ratio_), marker='o', linestyle='--')
plt.title('PCA 累計解釋變異率')
plt.xlabel('主成分數量')
plt.ylabel('累計解釋變異率')
plt.axhline(y=0.95, color='r', linestyle='--', label='95% 解釋變異閾值')
plt.grid(True)
plt.legend()
plt.show()
```

**【ANALYSIS】領航員深度解析**
> 從圖中可以看出，大約前 30 個主成分就幾乎解釋了原始 64 維數據 95% 的資訊。這意味著我們可以將特徵數量減半，而只損失少量資訊。

**【CODE】執行程式碼：執行 PCA 降維至 2 維以便視覺化**

```python
pca_2d = PCA(n_components=2, random_state=42)
X_pca = pca_2d.fit_transform(X_scaled)

plt.figure(figsize=(8, 6))
sns.scatterplot(x=X_pca[:, 0], y=X_pca[:, 1], hue=y, palette='viridis', s=50, alpha=0.8)
plt.title('PCA 降維結果 (2D)')
plt.xlabel('主成分 1')
plt.ylabel('主成分 2')
plt.legend(title='Digit')
plt.show()
```

## 🚀 步驟 2：t-SNE - 非線性降維（視覺化利器）

**t-SNE** 是一種強大的**非線性**降維技術，特別擅長於高維資料的視覺化。它能捕捉到 PCA 無法識別的複雜流形結構。

**注意**: t-SNE 計算成本高，且其降維後的點間距離沒有實際意義，主要用於**觀察群集**。

**【CODE】執行程式碼：執行 t-SNE 降維**

```python
from sklearn.manifold import TSNE

print("--- 正在執行 t-SNE 降維，這可能需要一些時間... ---")
tsne = TSNE(n_components=2, perplexity=30, random_state=42)
X_tsne = tsne.fit_transform(X_scaled)
print("✅ t-SNE 降維完成。")

plt.figure(figsize=(8, 6))
sns.scatterplot(x=X_tsne[:, 0], y=X_tsne[:, 1], hue=y, palette='viridis', s=50, alpha=0.8)
plt.title('t-SNE 降維結果 (2D)')
plt.xlabel('t-SNE 維度 1')
plt.ylabel('t-SNE 維度 2')
plt.legend(title='Digit')
plt.show()
```

**【ANALYSIS】領航員深度解析**
> 與 PCA 相比，t-SNE 的結果中，各個數字的群集被分得更開，邊界更清晰。這展示了它在視覺化上的強大能力。

---

## 🚀 步驟 3：UMAP - 高效的現代降維選擇

**UMAP** 是 t-SNE 的一個現代替代品。它通常**速度更快**，並且在保留局部結構的同時，能**更好地保留數據的全局結構**。

**【CODE】執行程式碼：執行 UMAP 降維**

```python
import umap

print("--- 正在執行 UMAP 降維... ---")
umap_reducer = umap.UMAP(n_components=2, random_state=42)
X_umap = umap_reducer.fit_transform(X_scaled)
print("✅ UMAP 降維完成。")

plt.figure(figsize=(8, 6))
sns.scatterplot(x=X_umap[:, 0], y=X_umap[:, 1], hue=y, palette='viridis', s=50, alpha=0.8)
plt.title('UMAP 降維結果 (2D)')
plt.xlabel('UMAP 維度 1')
plt.ylabel('UMAP 維度 2')
plt.legend(title='Digit')
plt.show()
```
