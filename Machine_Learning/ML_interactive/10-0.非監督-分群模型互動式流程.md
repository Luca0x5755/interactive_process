import seaborn as sns

# 生成一個包含4個清晰群組的模擬資料
X, y_true = make_blobs(n_samples=300, centers=4, cluster_std=0.8, random_state=42)

plt.figure(figsize=(8, 6))

## 🚀 步驟 1：K-Means - 基於中心點的分群

**K-Means** 是最經典的分群演算法。它的目標是找到 K 個「群心 (Centroids)」，並使每個數據點到其所屬群心的距離平方和最小。

**優點**: 簡單、快速。
**缺點**: 需要預先指定群數 K，且對非球形的群體效果不佳。

**【CODE】執行程式碼：使用手肘法尋找最佳 K 值**
> 我們透過計算不同 K 值下的「群內誤差平方和 (WCSS)」，找到 WCSS 下降趨勢減緩的「手肘」點，以此來決定 K。

```python
from sklearn.cluster import KMeans

wcss = []
k_range = range(1, 11)
for k in k_range:
    kmeans = KMeans(n_clusters=k, random_state=42, n_init='auto')
    kmeans.fit(X)
    wcss.append(kmeans.inertia_) # .inertia_ 就是 WCSS

plt.figure(figsize=(10, 6))
plt.plot(k_range, wcss, marker='o', linestyle='--')
plt.title('K-Means 手肘法')
plt.xlabel('群組數量 (K)')
plt.ylabel('WCSS')
plt.xticks(k_range)
plt.grid(True)
plt.show()
```

**【ANALYSIS】領航員深度解析**
> 從圖中可以清晰地看到，K=4 是一個明顯的「手肘」，WCSS 在此之後下降趨於平緩。因此，我們選擇 K=4 進行分群。

**【CODE】執行程式碼：使用 K=4 進行分群**

```python
from sklearn.metrics import silhouette_score

kmeans = KMeans(n_clusters=4, random_state=42, n_init='auto')
y_kmeans = kmeans.fit_predict(X)

# 評估分群好壞：輪廓係數 (Silhouette Score)，越接近1越好
print(f"K-Means 輪廓係數: {silhouette_score(X, y_kmeans):.4f}")

# 視覺化結果
plt.figure(figsize=(8, 6))
sns.scatterplot(x=X[:, 0], y=X[:, 1], hue=y_kmeans, palette='viridis', s=50, alpha=0.8)
plt.scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1], s=200, c='red', marker='X', label='Centroids')
plt.title('K-Means 分群結果 (K=4)')
plt.legend()
plt.show()
```

## 🚀 步驟 2：DBSCAN - 基於密度的分群

**DBSCAN** 將群組定義為「高密度區域」。它不需要預設群數，還能有效找出「噪聲點」。

**優點**: 能發現任意形狀的群體，能識別噪聲。
**缺點**: 對 `eps` (鄰域半徑) 和 `min_samples` (核心點最小鄰居數) 兩個參數敏感。

**【CODE】執行程式碼：使用 DBSCAN 進行分群**

```python
from sklearn.cluster import DBSCAN

# eps 和 min_samples 的選擇通常需要實驗
dbscan = DBSCAN(eps=1.0, min_samples=5)
y_dbscan = dbscan.fit_predict(X)

# 評估分群好壞
# 注意：如果DBSCAN將所有點視為噪聲(-1)，或只分出1群，則無法計算輪廓係數
if len(set(y_dbscan) - {-1}) > 1:
    print(f"DBSCAN 輪廓係數: {silhouette_score(X, y_dbscan):.4f}")
else:
    print("DBSCAN 未能分出多個群組，無法計算輪廓係數。")

# 視覺化結果
plt.figure(figsize=(8, 6))
sns.scatterplot(x=X[:, 0], y=X[:, 1], hue=y_dbscan, palette='bright', s=50, alpha=0.8)
plt.title('DBSCAN 分群結果')
plt.legend(title='Cluster')
plt.show()
```

**【ANALYSIS】領航員深度解析**
> 在 DBSCAN 的結果中，標籤為 `-1` 的點被視為噪聲。這種能力在進行異常檢測時非常有用。

## 🚀 步驟 3：階層式分群 (Hierarchical Clustering)

**階層式分群**會建立一個樹狀的群組結構，稱為「樹狀圖 (Dendrogram)」。我們可以透過觀察樹狀圖來決定分群數量。

**優點**: 不需要預設群數，能提供豐富的階層結構視覺化。
**缺點**: 計算複雜度高，不適合非常大的資料集。

**【CODE】執行程式碼：繪製樹狀圖並分群**

```python
from scipy.cluster.hierarchy import dendrogram, linkage
from sklearn.cluster import AgglomerativeClustering

# 繪製樹狀圖來決定群數
linked = linkage(X, method='ward')
plt.figure(figsize=(12, 8))
dendrogram(linked)
plt.title('階層式分群 樹狀圖')
plt.ylabel('距離')
plt.axhline(y=20, color='r', linestyle='--') # 畫一條輔助線
plt.show()
```

**【ANALYSIS】領航員深度解析**
> 觀察樹狀圖，我們可以想像用一條水平線從上往下切割。紅色的虛線在 `y=20` 的位置切割了 4 次垂直線，這暗示著將數據分為 4 群是比較合理的。

**【CODE】執行程式碼：使用階層式分群**

```python
agg_cluster = AgglomerativeClustering(n_clusters=4, linkage='ward')
y_agg = agg_cluster.fit_predict(X)

print(f"階層式分群 輪廓係數: {silhouette_score(X, y_agg):.4f}")

plt.figure(figsize=(8, 6))
sns.scatterplot(x=X[:, 0], y=X[:, 1], hue=y_agg, palette='plasma', s=50, alpha=0.8)
plt.title('階層式分群結果 (K=4)')
plt.show()
```
