## 🚀 步驟 1：理解關聯規則的三大核心指標

在開始之前，必須理解衡量一條規則 `(如果A -> 那麼B)` 好壞的三個指標：

1.  **支持度 (Support)**
    *   **問**: 這個商品組合 `{A, B}` 有多**普遍**？
    *   **意義**: `{A, B}` 同時出現的交易次數 / 總交易次數。它過濾掉那些罕見的、無意義的組合。

2.  **信賴度 (Confidence)**
    *   **問**: 如果顧客買了 A，我們有多大**把握**他會買 B？
    *   **意義**: `{A, B}` 同時出現的次數 / 只出現 A 的次數。它衡量了規則的可靠性。

3.  **提升度 (Lift)**
    *   **問**: 買 A 這件事，對買 B 的**幫助有多大**？
    *   **意義**: `(買了A又買B的機率) / (B本身被購買的機率)`。它告訴我們這條規則是不是純屬巧合。
        *   `Lift > 1`: **有關聯！** 購買 A **促進**了 B 的購買。（我們最想找的！）
        *   `Lift = 1`: **沒關聯。** A 和 B 只是獨立事件。
        *   `Lift < 1`: **負相關。** 購買 A **抑制**了 B 的購買。

## 🚀 步驟 2：準備交易資料

關聯規則演算法的輸入格式很特殊：一個 **One-Hot 編碼**的 DataFrame。其中每一**行**代表一筆**交易**，每一**列**代表一個**商品**，值為 `True`/`False` 表示該交易中是否包含該商品。

**【CODE】執行程式碼**
> 我們將使用 `mlxtend` 的 `TransactionEncoder` 來輕鬆完成這個轉換。

```python
from mlxtend.preprocessing import TransactionEncoder
import pandas as pd

# 假設我們有如下的交易清單 (List of lists)
dataset = [
    ['牛奶', '洋蔥', '肉豆蔻', '芸豆', '雞蛋', '優格'],
    ['蒔蘿', '洋蔥', '肉豆蔻', '芸豆', '雞蛋', '優格'],
    ['牛奶', '蘋果', '芸豆', '雞蛋'],
    ['牛奶', '獨角獸', '玉米', '芸豆', '優格'],
    ['玉米', '洋蔥', '洋蔥', '芸豆', '冰淇淋', '雞蛋']
]

te = TransactionEncoder()
te_ary = te.fit(dataset).transform(dataset)
df_trans = pd.DataFrame(te_ary, columns=te.columns_)

print("--- One-Hot 編碼後的交易資料 ---")
display(df_trans)
```

## 🚀 步驟 3：使用 Apriori 演算法找出「頻繁項集」

**Apriori 演算法** 的作用就是從所有可能的商品組合中，高效地找出那些**支持度 (Support)** 高於我們所設定的最小閾值的「頻繁項集」。這是生成規則的第一步。

**【CODE】執行程式碼**
> `min_support` 是一個關鍵參數。設定得太高，可能找不到任何項集；設定得太低，結果又會太多太雜亂。通常從一個較小的值開始嘗試。

```python
from mlxtend.frequent_patterns import apriori

# --- 使用者需修改的區域 ---
min_support_threshold = 0.6 # 我們只關心在至少 60% 的交易中都出現過的商品組合
# -------------------------

frequent_itemsets = apriori(df_trans, min_support=min_support_threshold, use_colnames=True)

print(f"\n--- 找到 {len(frequent_itemsets)} 個支持度 > {min_support_threshold} 的頻繁項集 ---")
display(frequent_itemsets.sort_values('support', ascending=False))
```

**【ANALYSIS】領航員深度解析**
> 這張表列出了所有「熱門商品組合」。例如，`support` 為 0.8 的 `{雞蛋, 芸豆}` 意味著在所有交易中，有 80% 的購物籃都同時包含了雞蛋和芸豆。這些組合是我們生成規則的基礎。

---

## 🚀 步驟 4：從頻繁項集中生成並篩選「關聯規則」

有了熱門組合，我們就可以從中推導出規則了。例如，對於 `{雞蛋, 芸豆}`，我們可以生成 `如果{雞蛋} -> 那麼{芸豆}` 和 `如果{芸豆} -> 那麼{雞蛋}` 兩條規則，並計算它們的信賴度和提升度。

**【CODE】執行程式碼**
> 我們將使用 `association_rules` 函數，並根據**信賴度 (Confidence)** 或 **提升度 (Lift)** 來篩選出真正有價值的規則。

```python
from mlxtend.frequent_patterns import association_rules

# --- 使用者需修改的區域 ---
# 選擇衡量指標 'confidence' 或 'lift'
metric_to_use = 'confidence'
min_metric_threshold = 0.7 # 我們只關心信賴度 > 70% 的規則
# -------------------------

rules = association_rules(frequent_itemsets, metric=metric_to_use, min_threshold=min_metric_threshold)

print(f"\n--- 找到 {len(rules)} 條 {metric_to_use} > {min_metric_threshold} 的關聯規則 ---")

# 顯示最重要的幾列，並按提升度(lift)和信賴度(confidence)排序
display(rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']].sort_values(['lift', 'confidence'], ascending=False))
```

**【ANALYSIS】領航員深度解析**
> **這是我們最終的成果！** 讓我們來解讀最有價值的一條規則：
> *   **規則**: `如果` 顧客購買了 `{洋蔥}` (`antecedents`), `那麼` 他們也很可能購買 `{雞蛋}` (`consequents`)。
> *   **Support (0.6)**: `{洋蔥, 雞蛋}` 這個組合在所有交易中佔了 60%。(夠普遍)
> *   **Confidence (1.0)**: 購買了 `{洋蔥}` 的顧客，**100%** 都購買了 `{雞蛋}`。(規則非常可靠)
> *   **Lift (1.25)**: 購買洋蔥這件事，讓顧客購買雞蛋的可能性**提升了 1.25 倍**。(真的有關聯！)
>
> **商業洞察**: 基於這條規則，商家就可以考慮將洋蔥和雞蛋放在相近的貨架上，或者設計「買洋蔥，雞蛋享折扣」的捆綁促銷活動。
