if isinstance(df_time.index, pd.DatetimeIndex):

## 🚀 步驟 2：滯後特徵 (Lag Features)

**滯後特徵**是時間序列預測中最強大的特徵之一。它的思想是：**用過去時間點的觀測值，來預測當前時間點的值**。例如，預測今天的銷售額，昨天、7天前的銷售額都是極其重要的參考。

**【CODE】執行程式碼**
> 我們使用 `.shift()` 方法來創建滯後特徵。注意，這會在數據開頭產生缺失值 (NaN)。

```python
if target_col in df_time.columns:
    print("--- 正在創建滯後特徵 ---")
    # --- 使用者需修改的區域 ---
    # 根據你數據的週期性來決定滯後間隔
    # 例如，每小時數據，24代表昨天同期；每週數據，7代表上週同期
    lag_intervals = [1, 7, 14] # <-- 假設是每日數據，我們關心昨天、7天前、14天前
    # -------------------------

    for lag in lag_intervals:
        df_time[f'{target_col}_lag_{lag}'] = df_time[target_col].shift(lag)
    
    print("✅ 滯後特徵創建完成。")
    display(df_time[[target_col] + [f'{target_col}_lag_{lag}' for lag in lag_intervals]].head(max(lag_intervals) + 2))
else:
    print(f"⚠️ 找不到目標欄位 '{target_col}'。")
```

## 🚀 步驟 3：滑動窗口特徵 (Rolling Window Features)

如果說滯後特徵是看「過去某一個點」，那滑動窗口就是看「過去一段時間」的**統計特性**（如平均數、標準差）。它能幫助模型捕捉近期的趨勢和波動性。

**【CODE】執行程式碼**
> 我們使用 `.rolling()` 方法。**關鍵點**：為了避免數據洩漏，我們計算完滑動統計後，必須再用 `.shift(1)` 將其後移一格，確保預測當前值時，只用到了過去的資訊。

```python
if target_col in df_time.columns:
    print("--- 正在創建滑動窗口特徵 ---")
    # --- 使用者需修改的區域 ---
    # 決定你的窗口大小
    window_sizes = [7, 14] # <-- 計算過去7天和14天的統計
    # -------------------------

    for window in window_sizes:
        # 先計算滑動統計量
        rolling_mean = df_time[target_col].rolling(window=window).mean()
        rolling_std = df_time[target_col].rolling(window=window).std()

        # 再進行 shift(1) 操作，避免數據洩漏
        df_time[f'{target_col}_roll_mean_{window}'] = rolling_mean.shift(1)
        df_time[f'{target_col}_roll_std_{window}'] = rolling_std.shift(1)

    print("✅ 滑動窗口特徵創建完成。")
    display(df_time[[target_col, f'{target_col}_roll_mean_7', f'{target_col}_roll_std_7']].dropna().head())
else:
    print(f"⚠️ 找不到目標欄位 '{target_col}'。")
```

## 🚀 步驟 4：週期性特徵轉換 (Cyclical Feature Transformation)

像 `hour` (0-23) 或 `month` (1-12) 這類特徵，其本質是循環的。我們使用 `sin` 和 `cos` 轉換，可以將這種循環關係映射到一個圓上，讓模型更好地理解其週期性。

**【CODE】執行程式碼**
> 我們將對 `dayofweek` 和 `month` 進行週期性編碼。

```python
if 'dayofweek' in df_time.columns and 'month' in df_time.columns:
    print("--- 正在創建週期性特徵 ---")
    # 處理星期
    df_time['dayofweek_sin'] = np.sin(2 * np.pi * df_time['dayofweek'] / 7)
    df_time['dayofweek_cos'] = np.cos(2 * np.pi * df_time['dayofweek'] / 7)

    # 處理月份
    df_time['month_sin'] = np.sin(2 * np.pi * df_time['month'] / 12)
    df_time['month_cos'] = np.cos(2 * np.pi * df_time['month'] / 12)
    
    print("✅ 週期性特徵創建完成。")
    # 繪圖展示週期性
    df_time.plot.scatter('month_sin', 'month_cos').set_aspect('equal')
    plt.title('Month Cyclical Encoding')
    plt.show()
else:
    print("⚠️ 找不到 'dayofweek' 或 'month' 欄位。")
```

**【ANALYSIS】領航員深度解析**
> 觀察 `sin`/`cos` 特徵繪製出的散點圖，你會看到一個完美的圓形。這就告訴模型，這些特徵是連續且循環的。例如，12月和1月在圓上的位置是相鄰的，這比它們在數軸上的距離 (1 vs 12) 更能反映真實情況。
