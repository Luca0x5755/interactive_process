# 文件領航員 (Document Navigator)

將任意文件轉為互動式流程導覽：產生 mermaid 流程圖，並以嚴格引用文件內容的方式，逐節點提供相關資訊。提供兩種用法——直接導覽，或先產出一份該文件專屬的客製導覽提示詞供日後重複使用。

## 如何開始 (Getting Started)

### 用法一：直接導覽

適合一次性閱讀：上傳文件即開始導覽，不留下成品。

1.  **初始設定**:
    將 `dn-interactive-process-zh-TW.md` 檔案，連同您想導讀的文件，一併上傳至您的語言模型。

    接著，發送以下提示詞以啟動領航員：
    > 你是「文件領航員」。請完整遵循 dn-interactive-process-zh-TW.md 中定義的角色、流程與輸出硬約束：先分析我上傳的文件，在同一則回覆內依序輸出文件概覽、流程來源判定、節點清單與出處對照表、mermaid 流程圖與指令表，然後以循序引導＋可跳選的方式帶我逐節點導覽。所有資訊必須嚴格引用文件內容並標註出處，文件未涵蓋的內容請明說。

### 用法二：產出客製導覽提示詞（造提示詞的提示詞）

適合重複使用：經「提案→確認→產出」流程，製造一份該文件專屬的導覽提示詞。日後將成品與原文件一起上傳給任何 LLM，即可直接開始導覽，不必每次重新分析。

1.  **初始設定**:
    將 `dn-generator-zh-TW.md` 檔案，連同您的文件，一併上傳至您的語言模型。

    接著，發送以下提示詞以啟動生成器：
    > 你是「文件領航員生成器」。請完整遵循 dn-generator-zh-TW.md 中定義的角色、流程與輸出硬約束：先分析我上傳的文件，在同一則回覆內輸出文件概覽、流程來源判定、節點清單與出處對照表、mermaid 流程圖草案與製造指令表；等我輸入「定稿」後，再依成品模板以單一代碼區塊輸出該文件專屬的客製導覽提示詞。

2.  **保存與使用成品**:
    將產出的代碼區塊內容存為 `nav-<文件名>-zh-TW.md`。日後與原文件一併上傳給 LLM，發送「請完整遵循這份導覽提示詞，帶我導覽所附文件」即可。

## 特色 (Features)

- **通用**：SOP、教學、規格書、論文等任意文件皆可；文件已含流程就忠實抽取，沒有就由 AI 歸納並明確標示。
- **嚴格引用**：所有資訊只來自文件本身，逐點附出處，杜絕幻覺。
- **導覽協定**：`下一步`／`N`／`圖`／`深度 淺|深`／`測驗`／`調整流程圖`／`結束`。
- **可重複使用的成品**：用法二的成品內嵌同一套導覽協定與該文件專屬的流程圖；導覽指令與體驗和用法一一致（成品開場直接顯示流程圖，不重做分析）。
