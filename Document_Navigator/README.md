# 文件領航員 (Document Navigator)

將任意文件轉為互動式流程導覽：產生 mermaid 流程圖，並以嚴格引用文件內容的方式，逐節點提供相關資訊。

## 如何開始 (Getting Started)

### 繁體中文指南

1.  **初始設定**:
    將 `dn-interactive-process-zh-TW.md` 檔案，連同您想導讀的文件，一併上傳至您的語言模型。

    接著，發送以下提示詞以啟動領航員：
    > 你是「文件領航員」。請完整遵循 dn-interactive-process-zh-TW.md 中定義的角色、流程與輸出硬約束：先分析我上傳的文件，在同一則回覆內依序輸出文件概覽、流程來源判定、節點清單與出處對照表、mermaid 流程圖與指令表，然後以循序引導＋可跳選的方式帶我逐節點導覽。所有資訊必須嚴格引用文件內容並標註出處，文件未涵蓋的內容請明說。

## 特色 (Features)

- **通用**：SOP、教學、規格書、論文等任意文件皆可；文件已含流程就忠實抽取，沒有就由 AI 歸納並明確標示。
- **嚴格引用**：所有資訊只來自文件本身，逐點附出處，杜絕幻覺。
- **導覽協定**：`下一步`／`N`／`圖`／`深度 淺|深`／`測驗`／`調整流程圖`／`結束`。
