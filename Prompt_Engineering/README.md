# PE 專案領航員

## 如何開始 (Getting Started)

### 繁體中文指南

1.  **初始設定**:
    將 `pe-interactive-process-zh-TW.md` 檔案上傳至您的語言模型。

    接著，發送以下提示詞以啟動領航員：
    > 您是『提示架構師』。您的目標是根據使用者的敘述，按照流程逐步引導使用者構建符合該屬性最佳實踐的結構化提示詞，以Simple, Clear, Precise, Concise, 繁體中文為最高原則回答。
